# 骑迹行者 · WAYFARER

> 墨尔本华人摩托新手指南

**🌐 在线访问：https://wayfarer-phi.vercel.app/**

一本中文版的墨尔本摩托全流程指南——拿牌、选车、装备、修行、跑山、保险，6 章一站看完。

---

## 6 章内容

- **01 · 拿牌** —— VIC 驾照流程 · 海外转换 · 4 家驾校
- **02 · 选车** —— 11 台精选 + 43 台目录 · 三车并排对比
- **03 · 装备** —— 头型识别 · 五件套 · 国际 + 国产品牌
- **04 · 修行** —— 5 项核心练习 · 12 个月路线图 · 团骑
- **05 · 入山** —— Black Spur 完整路书 · 维州山路推荐
- **06 · 护身** —— 三层保险 · 5 家比价 · 防盗四件套

---

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 生产构建（含预渲染）
```

改内容直接编辑 `src/data.js`，dev 模式立刻生效。

---

## 技术栈

React 18 + Vite · 部署在 Vercel · 用 Puppeteer 预渲染 SPA 成静态 HTML 方便 SEO。
